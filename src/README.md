# Addis Café

A static Ethiopian café menu built with React and Vite.

## Technologies

- React
- Vite
- JSX
- CSS

## Features

- Reusable components
- Props
- JSX expressions
- map()
- React keys
- CSS styling
- Responsive design
- Ethiopian food and drinks
- Category-specific styling
- Restaurant location
- Footer

## Components

- `App.jsx` - Main application component
- `Header.jsx` - Restaurant header
- `Menu.jsx` - Menu data and menu list
- `MenuItem.jsx` - Reusable menu item component
- `Footer.jsx` - Restaurant footer

## How to Run

```bash
npm install
npm run dev
```
